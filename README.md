
# Jogo - ImageWord🖼️🔠

Projeto pessoal desenvolvido para se obter prática na linguagem de programação e em frameworks.

## 📌Sobre o Projeto
Trata-se de um jogo desenvolvido em HTML, CSS, JavaScript e Bootstrap com o objetivo de descobrir a palavra secreta seguindo pistas e observando elementos na imagem.

## 🎮Como Funciona
- O jogo possui uma imagem com diversos elementos que devem ser observados para encontrar a palavra secreta.
- Existem pistas que orientam o jogador sobre quais elementos buscar na imagem.
- Ao responder corretamente, o jogador recebe um feedback positivo, caso contrário, surge um feedback negativo para que continue tentando.
